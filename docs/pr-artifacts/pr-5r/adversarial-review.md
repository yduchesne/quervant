# PR 5-R — Adversarial review

Each surviving invariant is paired with a plausible way the rename could silently break it and the
independent check that would catch it. Counterexamples are audit reasoning, not mutations of
production fixtures.

| QR | Plausible break | Independent detector |
|---|---|---|
| QR-01 | One crate left at the old name, or a duplicate `crates/trawler-core` retained (e.g. a symlink) | `cargo metadata` enumerating exactly three `quervant-*` packages; `git ls-files \| grep -i trawler` in paths returns none |
| QR-02 | A stale `use trawler_core::…` left in a test that is `#[cfg]`-gated off, so it compiles but is never type-checked | `git grep -E 'trawler_core\|trawler-(core)' -- crates` must return nothing (grep is independent of compilation/test cfg) |
| QR-02 | Dependency key renamed but `path`/version left pointing at old dir | `cargo +1.85.0 check --workspace --all-targets` fails if the path is wrong; `cargo metadata` would resolve a missing package |
| QR-03 | A README/doc still brands the project Trawler in active prose | Classified postscan; every remaining active-doc match is listed as a retained historical/URL/marker exception |
| QR-04 | The fingerprint tag `trawler-analyzer-fingerprint-v1` is "cleaned up" to `quervant-…`, silently changing every analyzer fingerprint and segment byte | `segment_codec`/`segment_golden` byte comparisons plus `sha256(golden.seg)`; a fingerprint change also trips `AnalyzerFingerprintMismatch` tests |
| QR-04 | `golden.seg` regenerated by a "make tests pass" edit | Baseline/final SHA-256 equality check (`ebb07800…`); regeneration cannot reproduce the hand-authored fixture |
| QR-04 | `golden.tsv` comment rewritten, changing a golden fixture's bytes | Fixture digest recorded (`8eef6e0c…`); the file is excluded from the rename pass |
| QR-05 | `.trawler-tmp-<pid>-<counter>` recovery marker renamed to `quervant-tmp-`, so crash-left temp files leak and the physical-space ledger over-charges or under-recovers | A5 crash-temp tests assert exact `.trawler-tmp-*` recognition and malformed-lookalike rejection; renaming the grammar would fail them |
| QR-05 | Segment/cache object keys rebuilt from the crate name, changing durable keys | Source diff audit of `storage/key.rs`, `storage/segment.rs`, `segment/*` shows only import edits; no key constructor changed |
| QR-06 | A move of shared code across the ELv2/Apache boundary under cover of "rename" | `cargo metadata` licenses + unchanged `LICENSING.md` SPDX table and `LICENSES/*`; no code moved between crates |
| QR-07 | `cargo check` silently upgrades a third-party crate while refreshing the lockfile | `Cargo.lock` diff contains only the three local package entries; any third-party line would be a STOP |
| QR-08 | Env var renamed in code but not in the harness script (or vice versa), so the gate silently skips | `QUERVANT_PRODUCTION_S3_ADAPTER` referenced consistently in `run.sh` (consumer) and `README.md` (docs); default run prints SKIP with the new name |
| QR-08 | A compatibility alias silently reads the old env var | Grep for `TRAWLER_` across tracked files returns only historical ADR filenames, never an active read |
| QR-09 | Historical ADR/PR text bulk-rewritten by a global search-and-replace | `docs/decisions/**` and `docs/pr-artifacts/pr-3|pr-4|pr-5/**` show zero diff against `main`; occurrence inventory retains them |
| QR-09 | Historical GitHub URLs (`…/trawler/pull/N`) rewritten | Targeted protection keyed on `github.com/yduchesne/trawler`; postscan shows them intact |
| QR-10 | Agent attempts the GitHub repository rename itself | Owner performed the rename; the agent only changed the local remote (not committed) and the committed `Cargo.toml` URL. `git ls-remote https://github.com/yduchesne/quervant.git HEAD` resolves; no remote/settings mutation by the agent |
| QR-11 | Coverage drops below the floor because a renamed test is no longer discovered | `cargo llvm-cov … --fail-under-lines 85` exit status; the fresh run reports 85.25 % lines with the same 771 tests as baseline |
| QR-11 | A test only compiles under stable and fails on MSRV (or vice versa) | Both toolchains run fmt/clippy/tests; both report 771/0/2 |
| QR-12 | An old-name crate alias or `[patch]` shim is left so PR 6 could accidentally target `trawler-core` | `cargo metadata` has no `trawler-*` package; no manifest `[patch]`/alias exists |

## Deliberate audit counterexamples exercised

1. **Active import:** `quervant_distributed/src/lib.rs` now calls `quervant_core::project_name()`;
   `git grep trawler_ -- crates` confirms the old form is gone (verified failing form removed).
2. **Historical URL:** `docs/ROADMAP_V01.md` lines 19–21 still contain `github.com/yduchesne/trawler/pull/…`
   and were confirmed unchanged.
3. **Persisted marker:** `.trawler-tmp-` appears in `storage/fs.rs`/`cache.rs`/`a3_io.rs` and is
   confirmed unchanged; the A5 suite exercises it.
4. **Env var:** `TRAWLER_F02_DIR` no longer appears anywhere; `QUERVANT_F02_DIR` appears in both the
   parent and child `env` calls of `storage_fs_integration.rs`.

## Residual risks

- **Repository URL / CI identity** (QR-10): resolved — the owner renamed the repository, the
  rename head was merged via PR #20, and `Cargo.toml` now points at
  `https://github.com/yduchesne/quervant`. Historical URLs intentionally retain the old name
  (GitHub redirects them).
- **`docs/TESTING.md` conflict markers**: pre-existing and intentionally untouched; a future
  documentation gate that parses this file could fail for reasons unrelated to the rename.
