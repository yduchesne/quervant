## Independent oracle

The test tabulates analyzed field lengths and `rust` term frequencies and asserts
them against the pinned `english`/`standard_folded` analyzers
(`cf_t08_oracle_tables_match_pinned_analyzers`), then computes BM25 with explicit
arithmetic (`reference_bm25`) — never production `compute_stats`/`bm25`. Ordering
is asserted with the documented tie rule (score descending, key ascending), so the
`d5`/`d6` and `d1`/`d2` ties are checked.
