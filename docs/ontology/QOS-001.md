# QOS-001 — Ontology semantic model

**Version 1.0-design · Approved conceptually · Post-v0.1**

## Identity, classes and membership

One indexed document represents each ontology instance. Instances have stable logical identity, at least one declared direct class, and may have multiple direct classes. Class inheritance is a DAG permitting multiple inheritance. Direct membership differs from effective membership inherited through the class DAG. Ontology definitions are index-local, versioned and pinned to the generation; cross-index inference is not required initially.

Asserted relationships are directed typed binary triples `(relationship,subject,object)`; set semantics apply. Inferred facts are not asserted facts. Physical segment document IDs do not identify ontology instances. Instance deletion removes all incident asserted edges and memberships atomically.

## Predicates

Class hierarchy: `IsChildClassOf`/`IsParentClassOf` are immediate; `IsDescendantClassOf`/`IsAncestorClassOf` are strict transitive. Membership: `IsDirectInstanceOf(i,c)`, `IsInstanceOf(i,c)`, `IsDirectTypeOf(c,i)`, `IsTypeOf(c,i)`. Instance hierarchy: `IsChildOf`/`IsParentOf` immediate; `IsDescendantOf`/`IsAncestorOf` strict transitive. Optional third hierarchy-family argument selects a named family; two-argument form uses the designated index default, and errors if none exists. Multiple named families are permitted. Use **Descendant**, never “Descendent”.

## Constraints and inference

Relationship characteristics include symmetric, transitive, reflexive, irreflexive, asymmetric, inverse and subrelationship. Domain and range validate **effective** class membership but do not automatically infer classes. Disjoint classes cannot share an effective instance. Invalid cycles and inferred contradictions reject the entire transaction.

All writes validate the complete final candidate state before publication. Validation failure, uncertainty, budget exhaustion or internal error rejects atomically. Query budget exhaustion must be explicit, never interpreted as false. Negative results require complete relevant evaluation. PIT readers use the definitions and data of their pinned snapshot.

Relationship role names are not automatically query operator names; see [QOS-002](QOS-002.md) and [QOS-004](QOS-004.md).
