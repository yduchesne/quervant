# QOS-003 — Ontology physical architecture

**Version 1.0-design · P-01–P-14 approved conceptually · Post-v0.1**

## Binding principles

- **P-01:** Asserted relationships authoritative; inferred relationships reproducible.
- **P-02:** Immutable segments share existing manifests and generation, refresh/commit/PIT lifecycle.
- **P-03:** Stable instance identities independent of segment document IDs.
- **P-04:** Forward/reverse adjacency, asserted mutation records and direct memberships.
- **P-05:** Asserted triple identity `(r,s,o)` has set semantics; multi-source provenance requires a separate future occurrence model.
- **P-06:** Segment add/remove mutations, latest visible mutation wins; tombstones retained as needed.
- **P-07:** Atomic deletion cascades to incident asserted edges, memberships and instance document.
- **P-08:** Snapshot reader merges segments, tombstones, visibility and duplicates.
- **P-09:** Precomputed class DAG closure and indexed effective class membership.
- **P-10:** Dependency-directed incremental validation with complete fallback; invalid, incomplete, exhausted or failed validation rejects; recheck against intervening writer changes before publish.
- **P-11:** Hybrid specialized adjacency/inverse/symmetry/subrelationship/reachability/class closure plus general tabled goal-directed positive recursive inference; optimization must preserve reference semantics.
- **P-12:** Query `NOT` requires completed evaluation; conclusive positive witness can terminate early; explicit budgets.
- **P-13:** Universal URN operator registry (QOS-004), snapshot-scoped inference cache with semantic fingerprints.
- **P-14:** Independent in-memory reference evaluator, property-based differential conformance, ≥85% automated line coverage.

## Refinements and scope

[QOS-003A](QOS-003A.md) fixes mutation encoding and recovery; [QOS-003B](QOS-003B.md) fixes adjacency and readers; [QOS-003C](QOS-003C.md) fixes invalidation and consistency.

All core ontology functionality belongs in standalone `quervant-core` initially, without distributed runtime dependencies. Distributed ontology inference is deferred. Compaction is physical-only, inferred caches disposable, local and ObjectStore-backed snapshot semantics equivalent. Binary format, ABI and exact codec remain future implementation design decisions.
