# QOS-004 — Universal operator URNs and namespace resolution

**Version 1.0-design · QN-01–QN-12 approved · Post-v0.1**

## Canonical identity

**QN-01:** Every query operator (lexical, Boolean, temporal, geo, ontology, custom) has a canonical URN, e.g. `urn:quervant:search:operators:match`, `urn:quervant:ontology:operators:is_ancestor_of`, `urn:quervant:geo:operators:within_radius`. Supersedes the old flat `urn:quervant:operators:*` form. **QN-02:** Canonical URN, not display name, determines semantic identity. **QN-03:** `urn:quervant:*` reserved for built-ins; custom domains may use their own namespace (e.g. `urn:myontology:*`). Using an unregistered URN NID does not constitute formal RFC 8141 registration.

## Names and scopes

**QN-04:** Default presentation name is final URN component snake_case converted to PascalCase; explicit `name` override allowed without changing URN. Old default name is not automatically an alias; `aliases` must be explicit. **QN-05:** Namespace prefix aliases are distinct from operator scope aliases. A scope may be a union of namespaces:
```yaml
operator_scopes:
  qv:
    - urn:quervant:search:operators
    - urn:quervant:ontology:operators
  search: urn:quervant:search:operators
  ontology: urn:quervant:ontology:operators
```
**QN-06:** Unqualified names resolve through configured default scope `qv`; qualified `search:Match`, `ontology:IsAncestorOf`, `myontology:IsSubordinateOf` resolve through their named scope. Full canonical URNs must be expressible (exact grammar deferred).

## Strict resolution

**QN-07:** Search every namespace in scope, deduplicate identical canonical URNs, and require exactly **one distinct** URN. Zero means unknown, more than one fatal ambiguity. Namespace order does not grant precedence; argument overloads cannot disambiguate. **QN-08:** Validate collisions both at registry configuration and query compilation, including aliases; no implicit global import or fallback.

## Custom operators

**QN-09:** Custom declarative operators are typed, pure and side-effect-free, delegating to bound built-ins or composing query expressions; no arbitrary code or inference-rule creation. Reject recursive operator-definition cycles. Example: `IsSubordinateUnitOf(A,B)` delegates to `IsDescendantOf(A,B,urn:myontology:families:organizational_unit)`. **QN-10:** Built-in semantics immutable; definitions version-pinned; index-local presentation overrides and explicit aliases may be configured.

## Naming and query plans

**QN-11:** Ontology predicate operator names follow `Is*`/`Has*` conventions; this does not constrain lexical/Boolean operators such as `Match` or `And`. Relationship definitions omit predicate verbs (`parent_of`, `member`); operator association is explicit, not inferred by string matching. **QN-12:** Compiled plans bind canonical URNs, operator-registry semantic fingerprint, ontology fingerprint and snapshot identity; query-specific scope configuration changes require revalidation.

Namespaces include ontology classes, properties, relationships, archetypes, characteristics, families and operators. Parser syntax and binary encodings remain future design tasks; semantic collision behavior is fixed.
