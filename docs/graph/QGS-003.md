# QGS-003 — Traversal semantics and execution

**Version:** 1.0-design | **Status:** conceptually approved | **Delivery:** unassigned.

## Decisions

- **TD-001.** Traverse one pinned directed multigraph snapshot. OUTGOING, INCOMING and BOTH directions preserve independent edge IDs; BOTH must not duplicate a self-loop solely via forward/reverse lookup.
- **TD-002.** Primitive `Neighbors`, `Expand`, bounded `Traverse`, `Reachable` and `Paths`; common BFS/DFS executor consumes a graph-reader interface independent of storage format.
- **TD-003.** Vertex-deduplicated neighborhood/reachability distinct from path enumeration modes WALK (repeats permitted), TRAIL (no repeated edge per path), SIMPLE_PATH (no repeated vertex per path). Parallel edges produce distinct path bindings. Cyclic enumeration requires a finite hop bound.
- **TD-004.** Shared mixed-query work meter: depth, vertices/edges/adjacency records examined, frontier/path state, results, bytes, memory, spill, remote I/O, deadline/cancellation. Success on an existential witness is allowed; false requires complete relevant evaluation; exhaustion never means false.
- **TD-005.** Deterministic algorithm-specific ordering: canonical IDs and edge IDs, BFS depth order, deterministic DFS edge expansion and path ordering. Compaction/order of segments may not change the declared result order.
- **TD-006.** Distinguish seed, edge eligibility, vertex-entry, continuation, terminal/result and whole-path predicates; use indexed search predicates and seek pushdown only where semantically equivalent.
- **TD-007.** Composable graph-first/search-first plans share typed IR, graph/document identity mapping and coherent snapshot; ranking of seeds is not automatic traversal ranking.
- **TD-008.** Active finite batch streaming with backpressure, cancellation, pinned snapshot and terminal success/error. Cross-request durable continuation deferred and requires full frontier/visited/path state or provable reconstruction.
- **TD-009.** Execution-local bounded frontier, visited and path state; optional bounded spill; disposable, non-authoritative.
- **TD-010.** Explicit NATIVE_GRAPH, ASSERTED_ONTOLOGY, EFFECTIVE_ONTOLOGY relationship domains. Inference not automatically included in native traversal; mixed domain composition explicit.
- **TD-011.** Location-independent batch-capable graph reader API; core does not depend on etcd or distributed services.
- **TD-012.** Independent reference evaluator, property-based graphs, cancellation/budget, local/RustFS and PIT differential tests.

## Semantic edge cases

A zero-hop traversal includes the start vertex only if query semantics permit it. Each emitted path lists ordered vertex/edge incarnations. Sorting and `LIMIT` cannot be pushed before path or distinct semantics without equivalence proof. Streamed partial batches are valid snapshot fragments, not evidence of completeness absent terminal success.

## Implementation boundary

Traversal operators and their bounded streaming primitives are QGS-003; weighted shortest paths, PageRank and communities are QGS-004; global search/graph planning QGS-005; cross-shard execution QGS-006.
