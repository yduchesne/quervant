# QGS-002 — Physical native graph storage

**Version:** 1.0-design | **Status:** conceptually approved | **Delivery:** unassigned.

## Approved storage decisions

- **SD-001.** Hybrid immutable segment deltas plus generation-aware latest-visible state. Reuse existing manifest, writer fencing, refresh/commit/PIT, local/ObjectStore codecs and retention; do not establish a mutable second authoritative graph database.
- **SD-002.** Graph-native vertex records govern existence, independently of optional indexed document associations. Stable vertex IDs and graph-qualified key mappings; ontology enrollment adds required indexed document semantics.
- **SD-003.** Edge record authoritative by independent edge ID; includes graph, source/target incarnations, canonical edge type and versioned property reference. QOS canonical `(relationship,subject,object)` assertion key remains logically distinct.
- **SD-004.** Four **logical** adjacency access paths: typed outgoing `(graph,source,type,target,edge_id)`; typed incoming `(graph,target,type,source,edge_id)`; all-type outgoing `(graph,source,target,type,edge_id)`; all-type incoming `(graph,target,source,type,edge_id)`. Physical implementations may share/compress keys, offsets and payloads; four full payload copies are not required. Must provide complete incident enumeration for deletions. Reverse/forward access paths reference the same authoritative edge state.
- **SD-005.** Immutable, ordered structural `assert/retract` delta and separate property versions; transaction sequence plus operation ordinal selects latest visible state. Property updates preserve edge identity/adjacency; structural type/endpoints immutable per edge incarnation. Validate final candidate and atomically publish.
- **SD-006.** Snapshot-bound, cancellable k-way adjacency merging across sorted seekable segment blocks. Resolve latest structural and property mutation, dictionary canonical type mapping, tombstones, endpoint visibility, dedup of replicated lookup paths and bounded fan-in/spill. Never resurrect obsolete state.
- **SD-007.** Vertex deletion completes incident-edge enumeration and retractions, including self-loop dedup and in-batch mutations, before atomic publish. Exhaustion fails transaction; lazy logical cascade needs separately proven design.
- **SD-008.** Adjacency excludes full property payload; selectively fetch stored typed properties, use ordinary indexed predicates and projection. Distinguish missing/null and property snapshot versions.
- **SD-009.** Compaction/GC preserve retained PITs, identities, adjacency and tombstone suppression; reclaim tombstones only after all older assertions and retention/recovery dependencies are safe.
- **SD-010.** ObjectStore authoritative immutable graph artifacts with bounded verified whole-file cache initially, seekable block bounds, corruption fail-closed, and future optional range-friendly formats. No whole-graph load at open.
- **SD-011.** Versioned snapshot-aware graph statistics (edge-type counts, vertex labels, degree distributions, property selectivity, bounds); approximations guide cost only and never prune without sound bounds.

## QOS alignment and non-equivalence

Reuse QOS-003A/B record layout machinery, dictionaries, snapshot cursors, publication and budgets where possible. Native multigraph structural keys include edge identity; QOS assertion keys do not. Inference belongs above the physical asserted-fact reader, not inside adjacency merging.

## Resource and verification contract

Limit cursor count, block/heap bytes, decoded records, result rows, remote bytes, deadline, cancellation, memory and spill. Independent in-memory multigraph oracle; mixed version dictionary, reassert/retract, deleted/recreated keys, high-degree deletes, multi-segment merge, PIT, compaction, corrupted remote artifact, crash-before/after-publish, RustFS cold/warm cache. No incomplete success.
