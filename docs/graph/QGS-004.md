# QGS-004 — Graph algorithms

**Version:** 1.0-design | **Status:** conceptually approved | **Delivery:** unassigned.

## Decisions

- **GA-001.** Every algorithm executes on a named, pinned, typed graph view with explicit scope, projection, direction, multigraph/self-loop and completeness semantics. Pre-algorithm graph filtering is not equivalent to filtering algorithm output.
- **GA-002.** Unweighted BFS and nonnegative weighted Dijkstra foundational shortest paths; bidirectional BFS, A*, k-shortest simple paths future extensions. Paths identify ordered edges. Reject negative/nonfinite Dijkstra weights. A* optimality needs an admissible heuristic. Deterministic optimal tie-breaking defined independent of heap timing.
- **GA-003.** Exact weakly/strongly connected components including isolated vertices; parallel edges do not alter component partitions. Complete, bounded processing required.
- **GA-004.** Exact in-degree/out-degree, unique neighbors, weighted degree. Parallel edges contribute to degree by multiplicity; self-loop contributes one incoming and one outgoing incidence. Local clustering later under explicit projection semantics.
- **GA-005.** PageRank first, then betweenness and closeness. Define dangling mass, normalization, convergence, parallel-edge collapse/preserve and weight transition rules. Approximate results must be labeled and parametrized.
- **GA-006.** Optional seeded deterministic label propagation initially; modularity/Leiden later. Community membership is not ontology class membership.
- **GA-007.** First-class GraphProjection: vertex/edge filters, direction, collapse/aggregation of parallel edges, self-loops, weight policy, temporal selection; explicit fingerprint. Native authoritative graph remains unchanged.
- **GA-008.** Cursor-based selective algorithms and disposable bounded CSR/CSC temporary projections for iterative global analytics; ephemeral dense ordinals never become entity IDs.
- **GA-009.** Typed results (scalar/path/component/vertex score) with graph snapshot, algorithm/version, projection, parameters, completeness, convergence/approximation metadata. Persisting scores/communities requires explicit ordinary mutation.
- **GA-010.** Bounded online streaming where safe; blocking until convergence/finalization for global scores, with explicit terminal errors, cancellation and fair admission.
- **GA-011.** Search-derived candidate restrictions and explicit ontology relation projections, never implicit inferred-closure shortcut edges for shortest path.
- **GA-012.** Core algorithm semantics independent of distributed deployment; future frontier-based and iterative partitioned executor adapters.
- **GA-013.** Independent reference, differential tests for path optimality, graph components, PageRank convergence/dangling, communities/projections, recovery and budget behavior; reproducible sparse/dense/skewed graph benchmarks.

## Initial delivery bands

P0 BFS shortest path, Dijkstra, weak/strong components, degree and projections. P1 PageRank, bidirectional BFS, CSR/CSC. P2 A*, k-shortest, centrality and community enhancements. These bands are **not** release promises. Algorithm-specific mathematical preconditions must be validated before execution.
