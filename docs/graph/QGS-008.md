# QGS-008 — Temporal, weighted and attributed graphs

**Version:** 1.0-design | **Status:** conceptually approved | **Delivery:** unassigned.

## Decisions

- **TW-001.** Distinct immutable transaction generation/time, domain-valid time and external observation time. Half-open `[start,end)` UTC-normalized intervals with precision and explicit missing vs unbounded semantics.
- **TW-002.** Optional multiple disjoint valid intervals on vertex and edge incarnations, independently versioned from transaction visibility. Temporal endpoint validity policy explicit; no global implicit historical truth claim.
- **TW-003.** Typed AS_OF(t), OVERLAPS(a,b), CONTAINED_IN(a,b) graph views. Query may select both generation and domain time; neither implies the other.
- **TW-004.** Time-respecting path contains chronological edge-use instants with explicit waiting, vertex validity, duration and monotone-time policies. Different from static projection shortest path.
- **TW-005.** Static time-filtered BFS/Dijkstra first; earliest-arrival with zero-duration edges and explicit waiting next; latest-departure, fastest journey and durations later. Temporal state dominance must be proven before pruning.
- **TW-006.** Typed weight property/expression, objective, missing/invalid handling and parallel-edge aggregation. Dijkstra only finite nonnegative additive costs.
- **TW-007.** Algorithm-specific accumulation/comparison algebra (sum/minimum cost, min/max bottleneck, explicit conditional probability product where valid). No automatic mathematical interpretation of confidence.
- **TW-008.** Typed attributed projections distinguish topology-changing eligibility filters from ranking/weight expressions.
- **TW-009.** Immutable temporal property versions, adjacency-compatible interval bounds, optional interval index; conservative pruning over *all* intervals, never false negatives.
- **TW-010.** Retained generation plus domain valid time yields bitemporal interpretation, not indefinite historical retention. Backdated corrections create new committed versions, leave old PIT untouched.
- **TW-011.** Static temporal projections compose existing graph algorithms; inherently temporal algorithms have separate identities. Weighted PageRank uses nonnegative normalized transition weights.
- **TW-012.** Shared typed search/time/graph predicates in QGS-005 planner with safe pushdown; source observation time is distinct from edge valid time.
- **TW-013.** No implicit temporal QOS inference: timeless closure, pre-filtered inference and temporal entailment are distinct. Temporal ontology requires separately approved QOS-007 semantics.
- **TW-014.** Distributed temporal/weighted processing reuses QGS-006 graph-qualified snapshots, partition exchange, budgets, and termination proof; first destination seen does not prove minimum global weighted cost.
- **TW-015.** Differential interval/path reference evaluator, property tests at boundaries, multi-interval cases, invalid weights, PIT/backdated correction, RustFS, cross-shard chronology and benchmarks.

## Weight correctness notes

An edge cost, capacity, strength, confidence and conditional probability are different dimensions. Never multiply generic confidence scores or interpret ontology inference as probability. Store provenance/observation metadata without inventing validity or causal meaning.

## Delivery bands

P0 intervals, static time projection, typed weights, weighted Dijkstra, pruning. P1 earliest arrival, attributed/weighted analytics. P2 duration-bearing transitions, specialized weight algebras and distributed temporal algorithms. Temporal ontology and evolving graph analytics separately gated.
