# QGS-001 — Native graph data model and identity

**Version:** 1.0-design | **Status:** conceptually approved | **Delivery:** unassigned, post-v0.1.

## Binding decisions

- **AD-001 — Identity.** Vertex IDs are never-reused 128-bit UUIDv4-compatible incarnation IDs with collision detection, independent of physical doc IDs, shards and placement. An optional external key is unique within a named graph and may be reused after deletion without identity resurrection. Vertices may exist without searchable documents; document associations use immutable incarnation-aware references, not reusable keys. Ontology instances retain QOS-001's required indexed document and direct class membership.
- **AD-002 — Model.** Directed attributed multigraph: zero-or-more vertex labels, one canonical type per edge, independently identified parallel edges, self-loops, first-class edge properties. A native edge ID distinguishes duplicate endpoint/type combinations. This decision was approved separately and is not interchangeable with QOS canonical triple identity.
- **AD-003 — Properties.** Reuse Quervant typed scalar, timestamp, GeoPoint, JSON and multivalue semantics; distinguish missing and explicit null. Index selected fields using existing search infrastructure. Graph labels do not imply ontology classes; type names do not infer ontology assertions.
- **AD-004 — Lifecycle.** Atomic local graph mutations within the index generation; endpoint existence checked against final candidate state; vertex deletion cascades incident edges; edge delete by identity, not ambiguous endpoint triple. PIT remains immutable. No silent partial mutation on exhaustion.
- **AD-005 — Scope.** Multiple named graphs per index. Native vertex belongs to one named graph; initial edges remain intra-graph. Cross-graph connectivity/federation requires explicit later design. Graph-scoped external-key uniqueness; ontology uses a reserved index-level semantic domain rather than automatically enrolling every named graph.
- **AD-006 — Ontology mapping.** Native edges and asserted/inferred ontology facts are distinct typed relationship domains. Explicit versioned mappings are required. One or more edge supports may correspond to one canonical assertion, but raw edge existence alone never asserts it.
- **AD-007 — Time.** Transaction snapshot time, optional domain-valid time and external observation time are separate; QGS-008 defines advanced temporal semantics.
- **AD-008 — Operators.** Graph built-ins have canonical `urn:quervant:graph:operators:*` URNs, resolved with QOS-004's universal registry. No name-based implicit inference.

## Semantic contracts

An edge has stable `(edge_id, graph_id, source_vertex_id, target_vertex_id, type_id)`; its source, target and type cannot be changed in-place under the initial mutation model (delete and recreate). Edges and endpoints must be live in the selected snapshot. Distinct edge IDs always remain distinct until an explicit graph projection chooses to collapse them. The graph itself is independent of ontology enrollment and reasoning.

## Required verification

Duplicate parallel edges; reversed directed edges; self-loops; graph scoping; external-key delete/recreate; document association lifecycle; typed null/missing; PIT mutation isolation; ontology enrollment not inferred from labels. Test identities across compaction and shard placement. Byte codecs and public Rust API remain QGS-002 implementation decisions.
