# QGS-007 — Graph and ontology integration

**Version:** 1.0-design | **Status:** conceptually approved | **Delivery:** unassigned.

## Precedence

[QOS-001–QOS-004](../ontology/README.md) remain authoritative for ontology instance documents, canonical asserted triple set semantics, positive inference, constraints and operator URNs. QOS-005 explanation/provenance and QOS-008 hypothetical state reasoning remain **unapproved**. QOS-007 temporal inference and QOS-009 agent interfaces require separate approval and reconciliation. QGS approval is NOT an approval of those proposals.

## Decisions

- **GO-001.** NATIVE_GRAPH (individual edge IDs), ASSERTED_ONTOLOGY (canonical triple keys), EFFECTIVE_ONTOLOGY (entailed fact set) are distinct query domains; no implicit conversion or materialized fictional edge IDs.
- **GO-002.** Optional ontology enrollment shares live vertex incarnation and requires one indexed instance document, at least one direct ontology class and atomic validation. Graph labels alone do not entail class membership.
- **GO-003.** Versioned, fingerprinted native edge-type → ontology relationship mappings with explicit endpoint enrollment, qualifying conditions, authority and support policies. Names/URN resemblance cannot assert.
- **GO-004.** Two authority modes: EXPLICIT authoritative caller assertions; MANAGED_MAPPING where qualifying support-edge sets contribute an assertion through an owner-scoped authoritative support ledger. Logical ontology fact remains set-based. Removing last managed support retracts only that authority's contribution; independent explicit authority remains. Requires explicit QOS-003A compatibility amendment before implementation, including retention, authorization, idempotency and conflict semantics.
- **GO-005.** Edge identities, support references and caller-supplied opaque provenance can be linked; evidence source-of-truth stays with caller. No invented or silently reassigned evidence.
- **GO-006.** Only QOS-002 positive least-fixed-point evaluator provides logical inference. Native graph algorithms do not automatically traverse inferred closure; effective-fact projections must be explicit.
- **GO-007.** In one local private candidate: graph changes → enrollment → authority/support reconciliation → canonical fact changes → QOS inference/invalidation/constraint validation → atomic generation publication. Exhaustion or inconsistency rejects entire candidate.
- **GO-008.** Typed IR joins native edge bindings with ontology membership/inference sources; preserve graph bag multiplicity versus fact-set results.
- **GO-009.** Transaction, validity and observation time stay distinct; no temporal entailment from timestamps alone.
- **GO-010.** Confidence scores are graph/support metadata, not inferred probabilities or attribution. Explicit filters may affect qualifying supports under fixed mapping semantics.
- **GO-011.** Structural edge-path explanations can link to logical assertion/rule witnesses, but proof encoding, completeness and caching remain pending QOS-005 approval.
- **GO-012.** QOS-004 URN/operator resolution and fingerprint binding extended by mapping identity/version; compiled plans require revalidation on semantic changes.
- **GO-013.** Distributed native graph does not imply distributed ontology transaction/inference. Global QOS validation, qualified snapshots and synchronization require separate protocol gates.
- **GO-014.** Machine-readable graph/ontology catalog for future agent discovery: names, types, canonical operators, relationship definitions, signatures, capabilities, version and constraints. Agent proposals compiled/validated; no LLM in graph core.
- **GO-015.** Independent reference model and differential tests for multiple supports, last support, separate explicit authority, invalid enrollment, rule changes, PIT, crash, distributed safety exclusions and explanation boundaries.

## QOS amendment gate

Before implementation, amend QOS-003A/B/C deliberately to add authority/support metadata without weakening set-based triples, final candidate validation, DRed retractions, deletion invariants or assertion authorization. Treat unmapped native edges as non-asserted. Reconcile with QOS-005 proposal, QOS-007 temporal work and QOS-009 catalog separately.

## Safety boundary

Graph reachability is not ontology logical entailment. Entailment is not observational fact, causal attribution, probability or a confirmed privilege escalation. QOS-008's hypothetical-state solver is out of scope.
