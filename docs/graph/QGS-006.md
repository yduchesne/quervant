# QGS-006 — Distributed native graph processing

**Version:** 1.0-design | **Status:** conceptually approved with mandatory unresolved protocol gates | **Delivery:** post-v0.2, unassigned.

## Mandatory precedence

Inherit [distributed design register](../distributed/README.md): stable logical shards, document routing, independently fenced shard writers, validated Publication Authority, ObjectStore authority, per-shard atomicity (NOT distributed transactions), EXACT/AT_LEAST/AVAILABLE generation-vector reads, global work reservations, and [C7 streaming](../distributed/07-STREAMING.md). Existing v0.2 explicitly excludes distributed joins/graph operators. No graph cluster or second publication pointer.

## Decisions

- **DG-001.** Stable vertex ownership by versioned deterministic graph/index identity routing to logical shard; independent of physical Search Node. Graph/document colocation must be an explicit creation/routing constraint; never silently alter existing document routing.
- **DG-002.** Source owner holds authoritative edge and outgoing adjacency; target may maintain derived reverse projection for incoming access. Projection completeness is qualified against pinned source generations; lag requires exact authoritative fallback or failure, never false absence.
- **DG-003.** Shard-local graph mutations atomic; remote endpoint existence checks alone insufficient to permit cross-shard edge creation/deletion under referential integrity. Cross-shard lifecycle requires DG-P1 before unrestricted mutation.
- **DG-004.** Exact pinned generation/manifest vectors are not atomic global graph states. Exact cross-shard graph semantics require a graph-qualified vector (DG-P2).
- **DG-005.** Depth-synchronous owner-routed batched BFS/frontier exchange with independently bounded RPC and compute. Complete round before advancing; DFS/path enumeration separate.
- **DG-006.** Partition vertex-deduplicated visited state by owner; TRAIL/SIMPLE_PATH need path-local edge/vertex histories, not global vertex dedup.
- **DG-007.** Extend existing C6 joins/exchanges with Gather, Broadcast, Repartition and FrontierExchange. Colocated/indexed lookup preferred when justified, pushdown proven equivalent.
- **DG-008.** Frontier algorithms and iterative bulk-synchronous vertex algorithms; PageRank convergence reduction, components reconciliation; weighted Dijkstra requires correct global priority/termination, not BFS approximation.
- **DG-009.** Reuse C7 source cursor and bounded distributed streaming. Distinguish internal work exchange and external results; final score/top-K emission only when proven final; no silent suffix loss or implicit resume.
- **DG-010.** Query/stage/shard/attempt identities plus superstep, stale message suppression, exact snapshot retry, optional immutable analytical checkpoints; coordinator changes cannot silently substitute generations.
- **DG-011.** One Aggregator-owned global budget with worker reservations across retries, frontier, adjacency, network, iteration, spill and intermediate state.
- **DG-012.** Initially stable simple placement. Measure cross-shard edge ratio, degree skew and exchange. Graph-aware partitioning/high-degree vertex splitting are future extensions; no implicit resharding.
- **DG-013.** Distributed native graph operations do not enable distributed QOS inference. Assertion ownership, global least-fixed-point and validation require separate qualification.
- **DG-014.** Authorization propagated and checked at shard and exchange boundaries; explain/count/path outputs cannot leak restricted relationships.
- **DG-015.** Standalone/distributed differential tests, real etcd/RustFS fencing and failure injection, exactly-once logical contribution, pinned vectors, work reservations and cold-cache benchmarks.

## DG-P1 — cross-shard graph mutation safety (mandatory, UNSPECIFIED)

Before enabling unrestricted cross-shard edges or deletes, design and prove a durable protocol for endpoint create/delete races, source-owned edge publication, target-located reverse projections, vertex incident-edge cleanup, idempotency, writer failover, partial shard outcomes, recovery and reference integrity. Evaluate graph-specific publication barriers versus multi-shard commit; **do not presume 2PC or per-shard batch atomicity provides a global transaction**. Define failure matrix, authority, rollback/compensation, linearization and quiescence/reclamation safety.

## DG-P2 — graph-consistent snapshot safety (mandatory, UNSPECIFIED)

Qualify exact generation vectors for graph referential/lifecycle coherence using durable dependency metadata/barriers and retention; pin projection provenance and source versions. Define read policy on incomplete qualification; prove no phantom/missing reverse edges, dangling endpoints or mixed versions. Plain EXACT(vector) pins independent shards but is not a globally atomic graph snapshot.

## Qualification gates

P0 DG-P1/DG-P2 protocol and proof before general mutations/queries; P1 frontier traversal; P2 distributed joins/planning; P3 algorithms; P4 graph-locality tuning. Real ObjectStore CAS and failure tests required. If DG-P1 or DG-P2 cannot be met, reject unsupported distributed graph operations rather than degrade exact semantics.
