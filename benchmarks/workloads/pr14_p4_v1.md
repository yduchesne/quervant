# Workload `pr14_p4_v1` — PR 14 P4 storage-mode benchmark

Status: versioned workload contract. `pr14_p4_v1` is a storage-mode comparison
(Quervant local `FsDirectory` vs Quervant real RustFS), **not** a cross-engine
claim and not a production p99 estimate.

## Corpus
- Deterministic synthetic corpus, 20,000 documents, three immutable segments,
  no mutations in the measurement lanes.
- Seed: `0x14F4_2026`. IDs `d00000..d19999`.
- Fields (PR 14 schema): `title` text (`standard_folded`), `host` keyword,
  `n` I64, `ts` Timestamp, `body` JSON `{"n": i % 10}`, `loc` GeoPoint
  `(i % 10, i % 10)`, `ip` `192.0.2.{i % 4}`.
- Digest: SHA-256 over `key\0title\0host\0n\0ts\0body\0loc\0ip` per document in
  ID order, emitted by the runner and required in every report.

## Query IDs and independent expected results
| ID | Query | Expected |
|---|---|---|
| W01 | mixed: `title:alpha AND n in [0,20000)` (cold-open+first query lane) | 10,000 |

| W07 | ordered 3-slot batch: aggregation success, invalid aggregation failure, plain success | S/F/S |
| W08 | forced cache eviction → reload → W01 | 10,000 (diagnostic lane) |
| W09 | local `FsDirectory` cold reopen → W01 | 10,000 |

Expected values are hand-derived from the corpus contract and asserted before
any timing; they are not copied from production output.

## Timing protocol
- 3 warmups + at least 20 measured samples per configuration.
- Local cold (W09) and remote cold (W01) time `open + first query`; warm lanes
  time query execution only against an already-open snapshot.
- Dataset generation, indexing, commit, oracle computation and cache warmup are
  outside the timed region.
- Local, remote cold and remote warm distributions are never pooled.
- Raw CSV: `target/pr14-p4/`; sanitized JSON: `benchmarks/reports/`.

## Qualification
A trial is qualified only with: correctness PASS, clean tree at the recorded
SHA, explicit `--idle-confirmed` operator attestation, contention `clear`, real
RustFS adapter exercised, all W01–W07/W09 measured, and no missing metrics.
Three independently qualified trials are required for publication.
