# PR 15B unified-search diagnostics workload contract — `pr15b_v1`

**Status:** frozen workload specification for PR 15B.
**Scope:** diagnostic measurement of whole-search work and latency. This contract
does not authorize a search-semantic change, a public API change, a persistence
format change or any performance optimization.

Changing any constant, formula, lane identifier, topology or timing boundary in
this document requires a new workload version (`pr15b_v2`) and new source-locked
evidence. Do not edit this file to match a measurement.

## 1. Provenance

- Canonical semantic fixture: `benchmarks/datasets/pr15a_v1.json`, immutable,
  SHA-256 `104d5ef0392edc43ac68f82d25288bea1394898e2a51dddac178cb7db8ecd087`.
- The eight canonical PR15A rows are the **semantic golden oracle**. They are
  never scalability evidence.
- `pr15b_v1` records are a deterministic synthetic scaling **extension** derived
  from the canonical row truth table. They have a different digest and must never
  be described as the canonical fixture.

## 2. Deterministic generator

For every corpus size `N ∈ {2000, 10000, 100000}` (and optional `1000000`):

```text
for i in 0..N:
    template = BASE_ROWS[i % 8]            # frozen PR15A row order
    key      = "d" + zero-padded 8-digit i
    title    = template.title
    host     = template.host
    n        = i
    ts       = 1_000_000 + i               # microseconds
    ip       = template.ip
    body     = template.body               # preserves null/absent/empty states
```

No random field, seed or clock is used. `N` must be positive and divisible by
eight. Records are assigned to `S` contiguous immutable segments with split
points `floor(j * N / S)` for `j = 0..S`; `S ≥ 1` and `S ≤ N`.

Template shares:

| predicate | template indices | exact share |
|---|---|---|
| `title=alpha` | `{0,1,4,7}` | `N/2` |
| `title=gamma` | `{3,4,5}` | `3N/8` |
| `title=delta` | `{6}` | `N/8` |
| absent lexical sentinel | none | `0` |
| `host=h2` | `{1,5,7}` | `3N/8` |
| `body.severity=2` | `{1,4}` | `N/4` |
| IPv4 `10.0.0.0/24` | `{0,1,7}` | `3N/8` |

### Digests

- `rows_sha256(N)`: SHA-256 over the version literal, big-endian `N`, then each
  canonical row line `i|key|title|host|n|ts|ip|severity|tags\n`, where severity
  is `null` or the integer and tags are `absent`, `empty`, or comma-joined.
- `corpus_sha256(N,S)`: SHA-256 over the version, `N`, `S`, every `(start,end)`
  boundary as big-endian `u64`, then `rows_sha256(N)`.

`DefaultHasher` and any host-dependent hash are forbidden. The same algorithm is
implemented once in `crates/quervant-core/benches/unified_diag_common/mod.rs` and
emitted as fixture metadata before timing.

## 3. Index and schema

`memory` directory only, for apples-to-apples query compute. The resident index,
immutable snapshot and segment bytes stay alive across every timed sample.

| field | type | cardinality | options |
|---|---|---|---|
| `title` | Text | Single | indexed+stored, `standard_folded` |
| `body` | Json | Single | indexed+stored, not columnar |
| `n` | I64 | Single | indexed+stored+columnar |
| `host` | Keyword | Single | indexed+stored+columnar |
| `ip` | IpAddress | Single | indexed+stored+columnar |
| `ts` | Timestamp | Single | indexed+stored+columnar, primary time field |

Fixture **build** limits are raised only as far as the prescribed topology
requires (`max_pending_docs`, `max_pending_bytes`, `max_snapshot_bytes`,
`max_segments_per_commit`). Search limits, query budgets and production defaults
are unchanged.

After build, the physical snapshot must report exactly `S` segments and `N` live
documents. A mismatch aborts the lane; `S` is never relabelled.

## 4. Mandatory workload matrix

`K` is the request's `top_k`; unspecified cases use `K=100`. A timed sample
executes exactly one production entrypoint call: `UnifiedSearcher::search` for
ordinary lanes, `execute_batch_pinned` for aggregation/batch/pagination lanes.

| ID | Lane (case/variants) | N/S | Request | Independent oracle |
|---|---|---|---|---|
| U01 | `absent` | 2K/4, 10K/4, 100K/4 | `title=zzzz_absent_15b` | exact empty set and total 0 |
| U02 | `rare` | 2K/4, 10K/4, 100K/4 | typed `n ∈ {0}` | exactly `d00000000` |
| U03 | `medium` | 2K/4, 10K/4, 100K/4 | `title=gamma` | total `3N/8`; returned keys are a unique subset of the exact full match set |
| U04 | `common-mixed` | 2K/4, 10K/4, 100K/4 | `title=alpha AND n ≥ N/2` | total `N/4`; unique subset of exact full match set |
| U05 | `cidr-time` | 10K/4 | `ip IN 10.0.0.0/24 AND ts` in production half-open `[TS_BASE+N/4, TS_BASE+N/2)` | exact ordered key sequence |
| U06 | `json-scalar` | 10K/4 | `body.severity == 2` | exact ordered key sequence |
| U07 | `sort-n` (`k10`,`k100`,`k1000`) | 10K/4 | `MatchAll`, numeric `n` ascending | exact prefix `d00000000…`; total `N` |
| U08 | `source`, `fields-host-n` | 10K/4 | `MatchAll`, `n` ascending, `K=100`, `Projection::Source` / `Fields(host,n)` | exact keys and exact five-state field values |
| U09 | `aggregate-host` | 10K/4 | `MatchAll` grouped by `host`, `count`, `sum(n)` | exact per-host count/sum; group cardinality `3` is the global exact-distinct host count |
| U10 | `serial-batch` | 10K/4 | one pinned batch, exactly U04, U05, U09 in that order | each slot key/total/aggregation equals its standalone execution |
| U11 | `rare`, `common-mixed` | 10K/1, 10K/4, 10K/16 | U02/U04 requests at each topology | logical result identical across `S` |
| U12 | `page-1`, `page-2` | 10K/4 | retained `PitHandle`, `n` ascending, page size 100 | page 1 `d0…d99`, page 2 `d100…d199`; full pagination concatenates to all `N` keys with no duplicate |
| U13 | `geo-bbox` | separate `geo_n8_s1` corpus | PR12-style `loc` GeoPoint, fixed inclusive bbox `[-10,-10,10,10]` | `g0,g1,g2,g3`; outside-everything bbox is empty |
| U14 | optional | 1M/4 or 100K/64 | U01–U04 or U11 | same formulas; never part of the required aggregate |

Required published lanes = U01–U13 as listed (30 Criterion lanes including the
three U07 K values, two U08 variants, six U11 topology variants and two U12
pages). U14 runs only with `QUERVANT_PR15B_LARGE=1` or
`QUERVANT_PR15B_SEG64=1` and is excluded from the required aggregate.

## 5. Timing semantics

- Fixture generation, indexing, flush/commit/reopen, snapshot capture, PIT
  creation, cursor discovery, oracle evaluation and metadata emission are
  **outside** every timed region.
- `Throughput::Elements(1)` for one whole request; no QPS label and no
  `Throughput::Elements(N)`.
- Criterion default statistics with `sample_size(20)`, `warm_up_time(3s)` and
  `measurement_time(5s)`. Criterion may legitimately extend measurement time for
  slow lanes; reported sample counts must remain `≥ 20`.
- Criterion estimates are **microbenchmark iteration distributions**, not
  production request p99 or a throughput SLA.
- A counter-enabled observation is never reported as an uninstrumented speed.
- An oracle mismatch aborts the process before qualifying timing.

## 6. Explicit exclusions and limitations

- `Projection::None` does not exist in the approved public contract. U08 runs
  `Source` and `Fields(host,n)`; the `None` variant is **not run** rather than
  inventing an API.
- The production `TimeRange` is half-open. U05 preserves that contract; the
  workload prose's "inclusive" wording is not implemented by changing search.
- Lexical/typed relevance top-K **selection order** beyond the eight-row canonical
  fixture is not independently re-scored. U03/U04 gate exact total count, exact
  returned length, uniqueness and membership in the independently computed full
  match set. The full set is materialized untimed where `N ≤ 100000`.
- U13 uses a separate fixed geometry corpus derived from the PR12 schema/query
  contract. It is not a measurement on the `pr15b_v1` corpus and is labelled
  separately in every report.
- No 1M or 64-segment lane runs in routine CI. No p99 SLO, cross-engine
  superiority claim or machine-independent absolute threshold is part of this
  contract.
